# Data of the course

This folder holds the public data files used by the Jupyter notebooks, so that the notebooks run without registration. [DATASETS.md](../DATASETS.md) gives the source, the license and the citation of every data set ([Türkçe](../DATASETS.tr.md)).

| Folder | Content | License |
|---|---|---|
| `uci-heart-disease/` | Cleveland data of the UCI Heart Disease data set | CC BY 4.0 |
| `physionet/mitdb/` | Record 100 of the MIT-BIH Arrhythmia Database | ODC-By 1.0 |
| `physionet/ptbdb/patient001/` | Record s0010_re of the PTB Diagnostic ECG Database | ODC-By 1.0 |
| `examples/` | Example caliper measurements created for the course | CC BY 4.0 |
| `downloads/` | The three data sets above as zip files, each with its citation and license, for the source *computer* of the data cells: Download a zip file, extract it and put its files next to the Jupyter notebook | as above |

The files are unchanged copies of the published files. The synthetic patients of the virtual clinic are not stored here: The course package `vclinic` creates them when a notebook runs.
