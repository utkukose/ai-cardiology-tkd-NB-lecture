# Start here

**Artificial Intelligence with Python: A Hands-on Training Program for Cardiologists**<br>
Turkish Society of Cardiology

[Course home](../../README.md) · [Setup](../../SETUP.md) · [Türkçe](../../tr/baslangic/README.md)

The notebook [NB00_start_here.ipynb](NB00_start_here.ipynb) prepares you for the course in about 30 minutes, before Week 1. It runs in the same way in Google Colab, with nothing to install, and in Jupyter on your own computer. It introduces both routes of the course: The prompt path, on which an artificial intelligence (AI) assistant writes the code from a ready prompt, a written instruction, and the Python path, on which you write the code yourself.

| | For whom? | What you do | Time |
|---|---|---|---|
| Section 0: Preparation | Everyone | Run the cells: The packages and the course folder are checked, and a first electrocardiogram (ECG) of the virtual clinic is drawn. | 10 min |
| Part 1: Prompt path | Participants who do not write code | Send a first prompt to an AI assistant, run the code it returns and check the result. | 10 min |
| Part 2: Python path | Participants who want to learn Python | Write the first lines of Python with clinical numbers. | 10 min |

The last cell prints **Ready for Week 1** when everything works.
