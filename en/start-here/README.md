# Start here

**Artificial Intelligence with Python: A Hands-on Training Program for Cardiologists**<br>
Turkish Society of Cardiology

[Course home](../../README.md) · [Setup](../../SETUP.md) · [Türkçe](../../tr/baslangic/README.md)

The Jupyter notebook [NB00_start_here.ipynb](NB00_start_here.ipynb) prepares the computer before Week 1 in about 30 minutes. It checks the Python packages, finds the course folder, introduces Jupyter and the first lines of Python with clinical numbers, and draws a first electrocardiogram (ECG) of the virtual clinic. It also sends a first prompt to an artificial intelligence (AI) assistant and checks the code that comes back. Its last cell prints **Ready for Week 1** when everything works.

Install Anaconda and download the course folder as described in [SETUP.md](../../SETUP.md), then open the notebook in Jupyter. If Anaconda cannot be installed, the notebook also runs in Google Colab: [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/utkukose/ai-cardiology-tkd-NB-lecture/blob/main/en/start-here/NB00_start_here.ipynb)
