# Start here

**Artificial Intelligence with Python: A Hands-on Training Program for Cardiologists**<br>
Turkish Society of Cardiology

[Course home](../../README.md) · [Setup](../../SETUP.md) · [Türkçe](../../tr/baslangic/README.md)

The notebook [NB00_start_here.ipynb](NB00_start_here.ipynb) prepares you for the course in about 30 minutes, before Week 1. It runs in the same way in Google Colab, with nothing to install, and in Jupyter on your own computer. It introduces the two ways in which code is produced in the course: An artificial intelligence (AI) assistant writes it from a ready prompt, a written instruction, or you write it yourself in Python.

| | For whom? | What you do | Time |
|---|---|---|---|
| Section 0: Preparation | Everyone | Run the cells: The packages and the course folder are checked, and a first electrocardiogram (ECG) of the virtual clinic is drawn. | 10 min |
| Part 1: A first prompt | Everyone; no code is written | Send a first prompt to an AI assistant, run the code it returns and check the result. | 10 min |
| Part 2: First steps in Python | Everyone who wants to learn Python | Write the first lines of Python with clinical numbers. | 10 min |

The two parts prepare you for the practice stops of the weeks, each of which has three parts in the Jupyter notebook: Python basics, Prompt and application, and Ready application. The last cell prints **Ready for Week 1** when everything works.
