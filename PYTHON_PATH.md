# Python basics

**Artificial Intelligence with Python: A Hands-on Training Program for Cardiologists**<br>
Turkish Society of Cardiology · First version: November 2026

[Course home](README.md) · [Türkçe](PYTHON_PATH.tr.md)

Every practice stop of a Jupyter notebook opens with its Python basics, for participants who want to learn to write the code themselves. The course assumes no programming experience. The Python basics of a stop teach the language that its ready application needs, with examples from the clinic and exercises that check their answers at once, and *Python note* cells explain every new construct where it first appears. The table lists the Python basics of the practice stops of all weeks with their topics and the section of the lecture page that they belong to.

Before Week 1, the [start-here notebook](en/start-here/NB00_start_here.ipynb) checks the computer and introduces cells, values, printing and a first plot.

In the part «Prompt and application» of the same stop, an artificial intelligence (AI) assistant writes the code from ready [prompts](PROMPT_PATH.md), and the part «Ready application» holds the complete program of the stop. Each part opens with a start cell, so it also runs on its own.
