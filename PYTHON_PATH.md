# Python path

**Artificial Intelligence with Python: A Hands-on Training Program for Cardiologists**<br>
Turkish Society of Cardiology · First version: November 2026

[Course home](README.md) · [Türkçe](PYTHON_PATH.tr.md)

The course assumes no programming experience. Each Jupyter notebook starts with a Python step right after its setup, and *Python note* cells explain every new construct where it first appears. The table lists the Python steps of the weeks. The steps of later weeks are planned and are linked when each week is published.

Before Week 1, the [start-here notebook](en/start-here/NB00_start_here.ipynb) checks the computer and introduces cells, values, printing and a first plot.

The same exercises can also be solved on the [prompt path](PROMPT_PATH.md), with prompts to an artificial intelligence (AI) assistant. There the Python of each step is learned by reading, running and explaining the code that the assistant writes.

| Week | Python step | Topics | Notebook |
|---|---|---|---|
| 1 | Python step 1: Values, lists, dictionaries, decisions, loops and functions | Variables and types, arithmetic with clinical values, lists and indexing, dictionaries, if and else, for loops, functions with arguments and return values, NumPy arrays, pandas DataFrames and Matplotlib plots | [NB01_python_and_ecg_basics.ipynb](en/week-01/NB01_python_and_ecg_basics.ipynb) |
| 2 | Python step 2: Data for models | Selecting columns and rows, missing values, dummy variables, splitting data by patient, the fit and predict pattern of scikit-learn, pipelines | In preparation |
| 3 | Python step 3: Arrays as images | Arrays with two and three dimensions, slicing, normalisation, loading images, the training loop of a neural network | In preparation |
| 4 | Python step 4: Reusing trained models | Loading pretrained weights, freezing layers, masks as arrays, functions that measure areas and volumes | In preparation |
| 5 | Python step 5: Signals in batches | Windows of a signal, arrays of many recordings, labels with several classes, reading a large data set step by step | In preparation |
| 6 | Python step 6: Working with text | Strings and their methods, regular expressions, tokens, calling a pretrained model from the Hugging Face Hub | In preparation |
| 7 | Python step 7: Classes and modules | Reading and writing a small class, importing code from modules, building a model from parts | In preparation |
| 8 | Python step 8: Joining data | Merging tables, aligning signals and images of one patient, dealing with missing parts | In preparation |
| 9 | Python step 9: Explaining a model in code | Calling explanation libraries, plotting attributions, comparing groups of patients | In preparation |
| 10 | Python step 10: From notebook to application | Scripts, a small web interface with Streamlit, saving and loading a model | In preparation |
| 11 | Python step 11: A project of one's own | Organising a project folder, documenting code, making results reproducible | In preparation |
